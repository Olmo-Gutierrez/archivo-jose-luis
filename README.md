# Archivo Artístico José Luis Gutiérrez

Catálogo Razonado y Archivo Histórico de la obra escultórica del artista **José Luis Gutiérrez**.

- **57 Obras Escultóricas** catalogadas (madera, cerámica y volumen en alambre).
- **38 Láminas de Cartulina** originales restauradas y digitalizadas.
- Interfaz interactiva inspirada en diseño editorial museístico contemporáneo.
